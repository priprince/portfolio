# pravin_portfolio

This repository hosts the **personal portfolio app** for Pravin D – a senior Flutter developer with a premium modern tech theme.

The Flutter application is built with Material3, custom theming, and responsive web support. It showcases:

- 🧠 **About** section with professional summary and stats
- 🔧 **Skills** categorized by technology domains
- 📁 **Featured Projects** illustrating real‑world apps with live Play Store links where available
- 💼 **Experience** timeline of senior roles and accomplishments
- 🎓 **Education & Certifications** highlighting academic background and credentials
- ✉️ **Contact** links to GitHub, LinkedIn, email, and social media

Developers can run the project with standard Flutter tooling (Windows, macOS, Linux, Web, Mobile).

For more details on theming and structure, refer to the `THEME_DOCUMENTATION.md` and `QUICK_REFERENCE.md` files.
